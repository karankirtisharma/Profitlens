# Synthetic evaluation and demonstration files

Generated by `python -m profitlens.evaluation_demo --export demo-files/evaluation` from the fixed v1 dataset. No real customer information is included.

1. In a chosen test workspace, import `customers.csv`, then `invoices.csv`, then `expenses.csv` through preview/confirm.
2. Upload a PDF to the customer in its filename. `*-current.pdf` covers 1 April–30 September 2026; reviewed monthly rate is INR 1000, discount 0, source page 1. `*-expired.pdf` is deliberately from 2025 and must not support 2026 answers.
3. Review source records and confirm costs through the analysis screen. Imports do not automatically attest completeness.
4. September `EVAL-01`–`05` contain pricing discrepancies; `06`–`10` contain cost increases/margin declines; `11`–`15` have deliberately missing September costs; `16`–`20` are controls. August is the comparison month.
5. `labels-and-questions.json` contains expected cases and 30 evaluation questions, including paraphrases and unsupported topics. These are deterministic synthetic labels, not measured customer outcomes.

For a fully prepared separate workspace instead, run `python -m profitlens.evaluation_demo --seed` after the normal demo account exists. This stores synthetic PDFs privately and records clearly labeled synthetic cost attestations. Repeated seeding preserves user edits.
